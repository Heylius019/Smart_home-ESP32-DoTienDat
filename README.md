
# Smart Home using ESP32

## Overview

A Smart Home system developed using ESP32, allowing users to monitor and control home devices through a mobile application.

## Features

- Remote control via Blynk
- Lighting control
- Fan control
- Temperature and humidity monitoring
- LCD display
- Security functions 

## Hardware

- ESP32
- Relay Module
- DHT11
- LCD1602
- I2C
- Sensors

## Software

- Arduino IDE
- Blynk
- Proteus
